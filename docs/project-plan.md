# 🩺 CareGuardian AI

## AI 기반 스마트 병동 자율 순찰 시스템

### 프로젝트 한 줄 소개

> **CareGuardian AI는 AI와 자율 순찰 로봇을 활용하여 병동을 실시간으로
> 모니터링하고, 환자의 통증·자세·낙상 위험을 분석하여 의료진이 가장 먼저
> 확인해야 할 환자를 우선적으로 추천하는 스마트 병동 플랫폼이다.**

**핵심 컨셉**

> 의료진을 대체하는 AI가 아니라 **의료진의 의사결정을 지원하는 AI
> 플랫폼**

# 🎯 문제 정의

## 산업군 소개

- 대상 산업: **의료 / 병원 병동 관리 (Smart Ward)**
- 핵심 인력: 병동 간호사, 야간 당직 의료진
- 시장 배경: 고령화 가속 → 입원 환자 증가, 간호 인력 부족 심화

## 업무 프로세스 (현재 병동 순회 방식)

``` text
간호사 라운딩(순회)
   │
병실 방문 → 환자 상태 육안 확인
   │
이상 발견 시 기록/보고
   │
다음 병실로 이동 (30~60분 주기 반복)
```

## Pain Point

- **간호사 1명이 야간에 환자 10~30명 이상 담당** → 물리적 사각지대 발생
- 순회 **주기 사이(30~60분)** 에 발생하는 통증 악화·낙상은 **뒤늦게 발견**
- 환자가 직접 호출벨을 누르지 못하는 상황(의식 저하, 통증으로 인한 무력감)에 취약
- 어떤 환자를 **먼저** 봐야 하는지 판단이 **경험·직감에 의존**

## 문제 발생 원인

- **인력 대비 환자 수 불균형** (구조적 문제)
- **연속 모니터링 부재** — 순회는 이산적(discrete), 위험은 연속적(continuous)
- **우선순위 판단의 비표준화** — 정량 지표 없이 사람이 판단

## 왜 중요한가

- 낙상·통증 악화의 **조기 발견 지연은 환자 안전·의료 사고와 직결**
- 야간·응급 상황에서 **골든타임 확보**가 생존·회복률을 좌우
- 의료진 **번아웃 완화** 및 간호 자원의 효율적 배분 필요

## 해결 방법 (CareGuardian AI)

- **연속 모니터링**: 카메라 기반 AI가 통증·자세·낙상 위험을 실시간 분석
- **정량화**: 환자 상태를 **PCI(환자 상태 지수)** 로 표준화
- **우선순위 자동화**: **AI Priority** 로 "먼저 봐야 할 환자"를 추천
- **물리적 확장**: 순찰 로봇이 위험 병실로 이동해 영상 확인·의료진 호출

# 🧠 PCI & AI Priority 로직

## PCI (Patient Condition Index, 0~100)

> 환자 상태를 하나의 숫자로 표준화한 지수. **높을수록 위급**.

``` text
PCI = 통증(Pain)    × 0.4
    + 자세위험(Posture) × 0.3
    + 낙상위험(Fall)    × 0.3
```

- **통증(Pain)**: 얼굴 표정(찡그림·미간·입 모양) 기반 통증 추정
- **자세위험(Posture)**: 비정상 자세(과도한 기울기, 침대 이탈 시도 등)
- **낙상위험(Fall)**: 균형 상실·급격한 움직임·낙하 패턴 감지

| PCI 범위 | 상태 | 표시 |
|---------|------|------|
| 0 ~ 39  | 정상 | 🟢 |
| 40 ~ 69 | 주의 | 🟡 |
| 70 ~ 100| 위험 | 🔴 |

## AI Priority 생성 규칙

1. 전체 환자를 **PCI 내림차순 정렬**
2. **급격한 PCI 상승**(단시간 내 큰 변화) 감지 시 **가중치 부여**
3. 상위 환자를 **"먼저 확인해야 할 환자"** 로 Dashboard 최상단 추천
4. 최상위 위험 환자 → **Robot Dispatch** 자동 제안

> ※ 가중치(0.4 / 0.3 / 0.3)는 임상 자문·데이터에 따라 조정 가능한 초기값.

# 📈 기대 효과

- **순회 사각지대 감소**: 이산적 라운딩 → 연속 모니터링 전환
- **우선순위 표준화**: 경험·직감 → PCI 기반 정량 판단
- **골든타임 확보**: 위험 조기 감지 → 대응 시간 단축
- **의료진 부담 완화**: 먼저 볼 환자를 AI가 추천 → 인지 부하 감소

> 정량화하고, 판단(AI Priority)과 물리 대응(Robot)을 하나로 연결.
